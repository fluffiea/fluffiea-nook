# 📓 Fluffiea Nook

> Fluffiea 的专属小角落，记录开发工具与工作流笔记。
> 用 Obsidian 打开，Graph View 可查看笔记间关联。

## 结构

```
nook/
├── SCHEMA.md        # 仓库规范
├── index.md         # 内容目录
├── log.md           # 变更日志
├── concepts/        # 概念说明、使用指南、踩坑记录
└── comparisons/     # 工具/方案横向对比分析
```

纯 Markdown，使用 LLM-Wiki 格式管理，直接通过 Obsidian 浏览编辑。所有 `.md` 文件均含 YAML frontmatter 和 `[[wikilinks]]` 双向链接。
